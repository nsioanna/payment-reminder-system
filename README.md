# Σύστημα Υπενθύμισης Πληρωμών

Αποστολή email υπενθύμισης σε χρήστες πριν από τη λήξη των λογαριασμών τους (<=3 μέρες πριν).
## Τι κάνει

- Διαβάζει τα στοιχεία χρηστών και των λογαριασμών τους από αρχείο JSON.
- Ελέγχει ποιοι λογαριασμοί λήγουν σε 3 ημέρες ή λιγότερο.
- Στέλνει ένα ενιαίο email ανά χρήστη, για όλους τους σχετικούς λογαριασμούς μαζί.
- Μετά από επιτυχή αποστολή, ενημερώνει την κατάσταση κάθε λογαριασμού σε "Ειδοποίηση - Στάλθηκε", ώστε να μην αποσταλεί ξανά.

## Δομή δεδομένων

Τα δεδομένα αποθηκεύονται στο `users.json`, ως dictionary όπου κάθε χρήστης έχει:
- `name`: όνομα χρήστη
- `email`: email χρήστη
- `accounts`: λίστα λογαριασμών, καθένας με `type` (κατηγορία), `amount` (ποσό), `expireDate` (ημερομηνία λήξης), και `status` (κατάσταση ειδοποίησης)

## Τεχνολογίες

- Python 3
- `smtplib` / `email` για αποστολή email
- `python-dotenv` για διαχείριση διαπιστευτηρίων
- Gmail SMTP (με App Password)

## Ρύθμιση και εκτέλεση

1. Εγκατάσταση εξαρτήσεων:
`pip install python-dotenv`
2. Δημιούργησε ένα αρχείο `password.env` στον ίδιο φάκελο (δεν περιλαμβάνεται στο repository, για λόγους ασφαλείας) με την εξής μορφή:
`EmailUsername=το_email_σου@gmail.com`
`AppPassword=ο_16ψήφιος_κωδικός_εφαρμογής`

   Ο κωδικός εφαρμογής (App Password) δημιουργείται από τις ρυθμίσεις ασφαλείας του λογαριασμού Google (απαιτείται ενεργοποιημένο 2FA).

3. Run
`python projectTwb.py`
